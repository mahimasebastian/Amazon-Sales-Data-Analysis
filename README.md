# 📖 Project Overview

This project analyzes Amazon sales data to uncover valuable business insights through **data cleaning**, **exploratory data analysis (EDA)**, **visualization**, and **interactive dashboarding**.

The objective is to understand sales performance, customer purchasing behavior, product demand, fulfillment efficiency, and geographical sales distribution to support data-driven business decisions.

---

# 🎯 Objectives

- 📈 Analyze overall sales trends
- 🛍️ Identify top-selling product categories
- 📦 Evaluate fulfillment methods
- 🌍 Analyze geographical sales distribution
- 👥 Understand customer purchasing behavior
- 💡 Generate actionable business insights
- 📊 Design an interactive Power BI dashboard

# ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/<your-username>/Amazon-Sales-Data-Analysis.git
```

2. Navigate to the project directory

```bash
cd Amazon-Sales-Data-Analysis
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Open the notebook

```bash
jupyter notebook
```

5. Run **Amazon_Sales_Analysis.ipynb**
